## Top 3 Priority Issues

1. TEST §7.2 — Co-located fixture factories are pervasive; migrate reusable builders to `tests/factories/` and import them across suites.
2. TEST §3.4 — Remove conditional branching from test bodies (notably `src/style/dsl.test.ts` and `src/parser/combinators.test.ts`) by splitting scenarios into dedicated tests.
3. TEST §7.1 / §1.3 — Replace inline object fixtures with typed factories and split combined boolean assertions into single-concept expectations.
